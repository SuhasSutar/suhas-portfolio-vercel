# Suhas Sutar — Portfolio

A modern, visually stunning portfolio website for a Full Stack Developer & Associate Manager with 11+ years of experience building scalable enterprise web applications.

## 🚀 Live Demo

[View Portfolio](https://suhas-sutar.github.io/suhas_sutar_portfolio/) *(update after deployment)*

## ✨ Features

- **Dark theme** with neon blue/purple gradients
- **Glassmorphism** cards and navigation
- **Smooth CSS animations** and hover effects
- **Fully responsive** (desktop, tablet, mobile)
- **SEO optimized** with semantic HTML5

## 📂 Sections

1. **Hero** — Animated intro with CTAs
2. **About Me** — Background & leadership highlights
3. **Experience** — Timeline at Mouritech (11+ years)
4. **Projects** — AI Translation Tools, Government Portals, Financial Platforms
5. **Skills** — Frontend, Backend, Tools
6. **Leadership** — Architecture, People Management, Client Delivery
7. **Contact** — Email form & social links

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Animations)
- Bootstrap 5.3
- Bootstrap Icons
- Google Fonts (Inter, Outfit)

## 📦 Setup

No build tools required. Simply open `index.html` in any modern browser.
